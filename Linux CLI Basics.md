## 1. Introduction to the Linux Terminal

The room started by introducing the Linux terminal and explaining why it is important in cybersecurity.

The terminal is a text-based interface that allows users to interact with an operating system by entering commands instead of using a graphical interface.

I learned that cybersecurity professionals regularly use the terminal because it provides more control over the system and makes it easier to perform tasks efficiently.

Some of the main advantages include:

- Faster interaction with the operating system.
- Greater control over files, directories and system settings.
- Access to security tools that operate through the command line.
- The ability to automate repetitive tasks using commands and scripts.

Before starting this room, I was more familiar with graphical interfaces, so learning how to interact with Linux through the terminal was an important step.

I also learned that CLI stands for **Command-Line Interface**.
